TEXT CODE PAGE (Cyrillic, Greek, Central European...)
=====================================================================

Check-in comments, labels, descriptions and names can now use code pages other than 1252: Windows-1251 (Cyrillic), 1250 (Central European), 1253 (Greek) and others. Before, the 2026 client always sent 1252: existing Cyrillic comments showed as "Ïîïðàâêà" instead of "Поправка", and new ones reached the server as "????".

How to configure (the first one found wins):
  1. On the server, for everybody: the line WireCodePage=1251 in the [GlobalUserData] section of jvcssrv.ini (folder of JVCSSrv.exe). Works with the current 2.5 server, no server update needed.
  2. On the workstation: the environment variable JVCS_WIRECODEPAGE or the string value WireCodePage in HKCU\Software\JEDI\JEDIVCS.
  3. Default: the Windows ANSI code page, as the original 2.5.0.1030 client did.

All workstations must use the code page the database was written with. Without any setting nothing changes on a workstation whose ANSI code page is 1252.

Where to see the code page in use:
  - Help > About > Version Information;
  - message window, when a project is opened ("Text code page: 1251 (server)").

Console jvcs.exe and AI automation:
  - stdin/stdout, /input and descriptionfile use the workstation code page;
  - the AI wrapper accepts wireCodePage= in config.ini;
  - edit-preserve writes ANSI sources in the Windows ANSI code page.
