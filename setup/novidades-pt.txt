=====================================================================
CODE PAGE DOS TEXTOS (cirílico, grego, Europa Central...)
=====================================================================

Comentários de check-in, labels, descrições e nomes agora podem usar outras code pages além da 1252: Windows-1251 (cirílico), 1250 (Europa Central), 1253 (grego) etc. Antes, o cliente 2026 mandava tudo em 1252: os comentários antigos em cirílico apareciam trocados ("Ïîïðàâêà" em vez de "Поправка") e os novos chegavam ao servidor como "????".

Como configurar (vale a primeira que existir):
  1. No servidor, para todos: a linha WireCodePage=1251 na seção [GlobalUserData] do jvcssrv.ini (pasta do JVCSSrv.exe). Funciona com o servidor 2.5 atual, sem atualizá-lo.
  2. Na estação: a variável de ambiente JVCS_WIRECODEPAGE ou o valor de texto WireCodePage em HKCU\Software\JEDI\JEDIVCS.
  3. Padrão: a code page ANSI do Windows (1252 no Brasil), como fazia o cliente original 2.5.0.1030.

Sem configuração, uma estação em português continua em 1252: nada muda para quem já usa.

Todas as estações precisam usar a code page com que o banco foi gravado.

Onde ver a code page em uso:
  - Help > About > Version Information;
  - janela de mensagens, ao abrir um projeto ("Text code page: 1252 (Windows ANSI code page)").

Console jvcs.exe e automação por IA:
  - entrada, saída, /input e descriptionfile ficam na code page da estação;
  - o wrapper da IA aceita wireCodePage= no config.ini;
  - o edit-preserve grava fontes ANSI na code page do Windows.
