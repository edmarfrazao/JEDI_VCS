Answers [issue #1](https://github.com/edmarfrazao/JEDI_VCS/issues/1): support for code pages other than 1252
(Cyrillic, Greek, Central European...).

## What changed

### Text code page
Check-in comments, labels, descriptions and names can use a code page other than 1252. Before, the 2026 client always
sent 1252: existing Cyrillic comments showed as `Ïîïðàâêà` and new ones reached the server as `????`. The first
setting found wins:

1. **Server, for everybody:** `WireCodePage=1251` in the `[GlobalUserData]` section of `jvcssrv.ini`. Works with
   the current 2.5 server.
2. **Workstation:** the `JVCS_WIRECODEPAGE` environment variable or the `WireCodePage` value in
   `HKCU\Software\JEDI\JEDIVCS`.
3. **Default:** the Windows ANSI code page, as the original 2.5.0.1030 client did; 1252 when Windows uses UTF-8.

### Where to see it
- **Help > About > Version Information**: code page in use and its source, the workstation one and where to set it.
- Message window, when a project is opened: `Text code page: 1251 (server)`.

### Console and AI
- `jvcs.exe`: stdin/stdout, `/input` and `descriptionfile` in the workstation code page.
- AI wrapper: `wireCodePage=` in `config.ini`. `edit-preserve` writes ANSI sources in the Windows ANSI code page.
