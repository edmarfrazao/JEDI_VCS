## What's new

### Choose each Delphi
Every installed IDE appears as its own option in the installer (Delphi 11, 12, 13 and the older ones). Only the checked
IDEs get the JEDI VCS expert; unchecking an IDE on a reinstall removes its registration. Silent installs use
`/COMPONENTS`, e.g. `/COMPONENTS="client,ide\bds23,ideold\bds10"` (Delphi 12 and XE3).

### Older IDEs: original expert + new core
The installer integrates **every IDE supported by the original JEDI VCS 2.5.0.1030**, pairing the original thin expert of
that version with the new core (`JvcsExternalDll.dll` 2.5.0.2026, same interface):

| Delphi | Expert |
|---|---|
| Delphi 7 | `JvcsExpertD7.dll` |
| 2005 · 2006 · 2007 | `JvcsExpertBDS3/4/5.dll` |
| 2009 · 2010 | `JvcsExpertBDS6/7.dll` |
| XE · XE2 · XE3 · XE4 · XE5 | `JvcsExpertBDS8…12.dll` |
| XE6 · XE7 · XE8 | `JvcsExpertBDS14/15/16.dll` |
| 10 Seattle · 10.1 · 10.2 · 10.3 · 10.4 | `JvcsExpertBDS17…21.dll` |
| 11 · 12 · 13 | new experts `JvcsExpertBDS22/23/37.dll` |

Delphi 5 and 6 are not included (they used the full old client, which cannot load the new core).

### AI
- The **`jedi-vcs`** skill for Claude Code ships with the installer (`tools\ai\skills\jedi-vcs`); guide in
  [`doc/ia`](../../doc/ia/README.md) (Portuguese) and [`doc/en/05-Using-with-AI.md`](../../doc/en/05-Using-with-AI.md).
- Wrapper: `status` without `-Project` ignores Windows copies (`X - Copy.dpr`).

### Performance
- **Project Manager opens faster** inside the IDE (from ~21 s down to under 1 s): only the icons actually used are copied.

### Documentation
- English documentation (main `README.md`, `doc/en`), news per language, changelog and a disclaimer the installer requires
  you to accept.

## Known issue
- **Older IDEs (e.g. Delphi XE3):** the new core's VCL sent action messages to the IDE's application window, and the
  IDE's (older) VCL crashed on them. A fix is in progress for the next beta. Meanwhile, use the standalone client
  (`Jedivcs.exe`) in those IDEs.
