## What it brought
- **Standalone client** (`Jedivcs.exe`), **Diff** (`JEDIVCSDiff.exe`) and **console** (`jvcs.exe`) built with Delphi 13,
  speaking exactly the same protocol as client 2.5.0.1030 (validated byte by byte against the original — "golden test").
- **Delphi 13.2 expert** + core `JvcsExternalDll.dll` with the same interface as the original.
- Features turned off by project decision: reports, translation, plugins, workstation notification; Branch menu hidden
  (branching servers still supported, always on HEAD).
- 2012 features kept: External Bugtracker, Save WIP, Compare all local/archive.
- AI tools (`tools\ai`): `jvcs-ai.ps1` wrapper, hooks and a Claude Code skill.
- Inno Setup installer and the MidWare license notice in About and in the console.
