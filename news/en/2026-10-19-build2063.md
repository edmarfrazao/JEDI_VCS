## What's new
- **`verify`:**
  - with no project set, the module is searched in **all projects** (1 project → used; 2 or more → `ambiguous`);
  - files that only live in Git (`.md`, `.ps1`...) are ignored by default (`verifyExtensions`);
  - `verify <file>...` checks single files without Git;
  - `-Text` shows the verdict.
- **Status summary:** a module with an error is counted once (`error`), so the sum matches the total.
- **Wrapper security fixes (review of 2026-10-17):**
  - `config set` requires typing `SIM` in the terminal;
  - `-Confirmed` from a calling script is not an approval;
  - `-Identity` other than the default needs approval;
  - `jvcs.exe` outside Program Files is pinned by SHA-256;
  - an unchanged `undocheckout` works in manual mode;
  - `sync` treats an older but writable, different file as a conflict;
  - `show -Dest` refuses project folders;
  - the hook blocks a `Write` that would recreate a deleted module;
  - permissions template 1.4.0 (run `instalar-no-projeto.ps1` again in your projects).
- **Known issue:** from the AI, `-Identity` equal to the folder's `[identities]` map still asks for `-Confirmed`.
