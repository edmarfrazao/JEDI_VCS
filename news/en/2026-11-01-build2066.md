## What's new
- **AI wrapper (S0003):** `add` of a long-named `.pas` + `.dfm` in one run could register the `.dfm` as a separate
  module; a file with the same base name as a long module but not a member of it (`.~pas`, `.sql`, `.bak`) was taken
  as versioned (now only member extensions such as `.dfm`, `.fmx`, `.res` count); `id:<n>` checks the identity of the
  module folder and queries the server inside the identity mutex.
- **Client:** Select All Matches no longer notifies docked windows once per module; a list refresh no longer
  overwrites what you are typing in Find; `Enter` in the project filter's group modes only opens a matching project;
  Open in Explorer needs exactly one module; `Esc` in a search field interrupts a project load again; `F3` in the
  Line History tab before the first search no longer jumps to the module Find.
- **Docs:** version table, Find delay in manual 04, manual 11 fixes.
- **Known issue:** from the AI, `-Identity` equal to the folder's `[identities]` map still asks for `-Confirmed`.
