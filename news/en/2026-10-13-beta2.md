**Date:** 2026-10-13 · **Tag:** [`v2.5.0.2026-beta2`](https://github.com/edmarfrazao/JEDI_VCS/releases/tag/v2.5.0.2026-beta2)

## Highlights

### Delphi 11, 12 and 13 integration
- One thin expert per version (`JvcsExpertBDS22/23/37.dll`, ~130 KB) plus **a single core** (`JvcsExternalDll.dll`).
- The expert uses only `rtl`, `vcl` and `xmlrtl` from the IDE, so it loads on **any update** (e.g. 13.0, 13.1, 13.2),
  verified with `tools\verificar-expert.ps1` against each update's packages.
- **No third-party components** are needed in the target Delphi (JCL, JVCL, ICS, Abbrevia, SynEdit and VirtualTreeView
  are compiled into the core).

### Appearance
- **Dark theme fixed:** project and module names readable, icons adapted to dark backgrounds.
- **"Follow Delphi"** uses the IDE's real theme (also when the theme changes with the IDE open).
- Readable menus in the dark IDE; JEDI VCS windows follow the IDE on Alt+Tab.
- **Appearance** page in VCS Properties: scaling, interface/menu/editor fonts, theme. Shortcut: **View → Appearance /
  Font Size…**.

### AI
- **AI / Automation** page in VCS Properties: manual / confirm / automatic modes for checkout and check-in, stored in the
  same `config.ini` used by `tools\ai\jvcs-ai.ps1`.

### Fixes
| Problem | Fix |
|---|---|
| Opening a project took ~21 s inside the IDE | system icons copied on demand (209 ms → 49 ms in the test) |
| Login cleared the identity's saved password | the password is cleared only if the user unticks "Store Password" |
| "No project" warning and Server Login opened together | shown one after the other |
| Compare all failed with "Invalid stream format" | text/binary detection fixed (Unicode) |
| Password-protected backup: Cancel made an **unprotected** backup | Cancel cancels |
| Line History access violation | pointer arithmetic fixed |
| Used Units split `Unit.Name` in two | lexer fixed |
| Windows cut off at 150–200% | minimum size from the scaled DFM |
| Errors without a trace | log in `%LOCALAPPDATA%\JEDI\JVCS\logs` (client, DLL and expert) |
