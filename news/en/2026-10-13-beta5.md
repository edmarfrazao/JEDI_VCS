## What's new

### Delphi XE3 and older IDEs: crash fixed
- **Fixed the access violation** when clicking JEDI VCS toolbar buttons (Synchronize, Get, Refresh…), the **Get**
  button of the revisions dialog, and menus/shortcuts inside Delphi XE3 and the other older IDEs.
- Cause: the core used the IDE's application window as its own, so the core's VCL sent the IDE messages carrying
  objects that the IDE's (different) VCL cannot read. The core now owns its application window (hidden, owned by the
  IDE). Details (Portuguese): [project lessons](../../doc/pt/processo/06-Problemas-Conhecidos-e-Licoes.md); English
  FAQ: [07-FAQ-and-Troubleshooting](../../doc/en/07-FAQ-and-Troubleshooting.md).

### Know which version is installed
Version numbers now follow **the original JEDI VCS pattern**: `2.5.0.<build>`, the build growing with each published
version (Beta 5 = **2050**, Beta 6 = 2060, final release = 2100). The number sent to the server at login stays **250**.

| Where | What you see |
|---|---|
| Window title (standalone and IDE) | `JEDI VCS (2.5.0 Beta 5 – build 2050)` |
| About (client, Diff, IDE) | `2.5.0 Beta 5 – build 2050` |
| Console `jvcs.exe` | `JEDI VCS console client 2.5.0 Beta 5 - build 2050` |
| Control Panel | `JEDI VCS 2.5 Beta 2026 (Beta 5, build 2050)` |
| File properties | version `2.5.0.2050`, "Beta Build", build date, `2.5.0 Beta 5 (2026)` |
| Installer name | `JediVCS-2.5.0-Beta5-build2050-Setup.exe` |
