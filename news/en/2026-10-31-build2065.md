## What's new
- **Module Find field:** `Ctrl+F` from anywhere; digits search too (`01` finds `Exemplo01.dpr`); contains, `*`/`?`
  masks, folder with `\`; exact names first; `Enter`/`F3` next, `Shift+Enter`/`Shift+F3` previous, `Ctrl+Enter`
  selects all matches, `Esc` clears; 300 ms default delay.
- **Project tree filter:** same rule as Find, case-insensitive, several words (all of them), matched text in bold,
  groups open while filtering and come back as they were; `Enter` opens the best match, `Down` goes to the tree
  without opening, `Esc` clears.
- **New Edit menu:** Find Module, Find Next/Previous, Select All Matches, Filter Projects (`Ctrl+Shift+P`, standalone
  only), Search Modules in All Projects (`Ctrl+Shift+F`), Copy, Copy Full Path (`Ctrl+Shift+C`), Select All. `Ctrl+C`
  and `Ctrl+A` act on the text inside a text field. The Line History tab and modal dialogs keep their own keys.
- **Module list context menu:** Copy Full Path, Copy Path, Open in Explorer, Search in All Projects.
- **AI wrapper (S0003):** modules whose names the console truncates at 30 characters are resolved by their full name;
  an unversioned file with the same prefix is no longer taken for its neighbour; `id:<n> -Project p` works in place of
  the file in `status`, `checkout`, `checkin`, `undocheckout`, `diff`, `history`.
- **Known issue:** from the AI, `-Identity` equal to the folder's `[identities]` map still asks for `-Confirmed`.
