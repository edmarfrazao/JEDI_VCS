## O que mudou

### Code page dos textos
Comentários de check-in, labels, descrições e nomes podem usar outra code page além da 1252. Antes, o cliente 2026
mandava tudo em 1252: os comentários antigos em cirílico apareciam como `Ïîïðàâêà` e os novos chegavam ao servidor
como `????`. Vale a primeira configuração que existir:

1. **Servidor, para todos:** `WireCodePage=1251` na seção `[GlobalUserData]` do `jvcssrv.ini`. Funciona com o
   servidor 2.5 atual.
2. **Estação:** variável `JVCS_WIRECODEPAGE` ou o valor `WireCodePage` em `HKCU\Software\JEDI\JEDIVCS`.
3. **Padrão:** a code page ANSI do Windows, como o cliente original 2.5.0.1030; 1252 se o Windows usa UTF-8.

Sem configuração, uma estação com ACP 1252 continua igual.

### Onde ver
- **Help > About > Version Information**: code page em uso e origem, a da estação e onde configurar.
- Janela de mensagens, ao abrir um projeto: `Text code page: 1251 (server)`.

### Console e IA
- `jvcs.exe`: entrada, saída, `/input` e `descriptionfile` na code page da estação.
- Wrapper da IA: `wireCodePage=` no `config.ini`. O `edit-preserve` grava fontes ANSI na code page do Windows.

### Instalador
Página de novidades antes da instalação, instalada como `NOVIDADES.txt`, com atalho no menu Iniciar.
